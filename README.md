# Brief — 밴드 실시간 메트로놈 & 파트 브리핑

한 방에 들어온 밴드 멤버들의 핸드폰/태블릿에서 **메트로놈 클릭과 음성 브리핑이 동시에** 재생되는 웹앱입니다.
방장이 ▶ 시작을 누르면 모든 기기에서 같은 순간에 카운트인 → 곡이 시작되고,
각 파트(Intro, Verse, Chorus …)가 시작하기 **한 마디 전**에 전자 음성으로 파트 이름을 알려줍니다.

앱 설치 없이 브라우저로 접속하면 되고, "홈 화면에 추가"하면 앱처럼 쓸 수 있습니다.

## 기능

- **메트로놈**: 마디 첫 박·새 파트 첫 박 강조, 6/8·9/8·12/8은 3박마다 중간 강세.
  - **박자**: 2/4, 3/4, 4/4, 5/4, 6/8, 7/8, 12/8 … (곡 기본값 + 파트별 변경)
  - **음표(쪼개기)**: 4분·8분·16분음표, 셋잇단음표, 16분 셋잇단 (곡 기본값 + 파트별 변경)
  - 곡 중간 박자 변경(예: 4/4 → 2/4 한 마디 → 4/4)은 편집기의 **"+ 박자 변경 마디"** 로 넣습니다.
    이 마디는 기본으로 브리핑을 하지 않고, 다음 파트 브리핑은 그 마디 첫 박에 나옵니다.
- **음성 브리핑**: 각 파트가 시작하기 한 마디 전, 그 마디 첫 박에 파트 이름을 알려줍니다.
  미리 녹음된 음성(여성/남성)을 박에 맞춰 예약 재생하므로 클릭과 정확히 맞습니다.
  "Verse 2", "코러스 1", "V1", "C" 같은 이름도 알아듣고, 녹음에 없는 문구(직접 쓴 한글 등)는 기기 음성으로 읽습니다.
- **카운트 음성**: 카운트인 마지막 마디를 "1 2 3 4" 또는 "1 n 2 n 3 n 4 n" 으로 셉니다.
- **곡 구조 편집**: 파트 이름·마디 수(− 8마디 +), 끌어서 순서 바꾸기, 파트 사이 "+"로 끼워넣기,
  파트별 BPM·박자·음표·음성 문구·브리핑 켜고 끄기.
- **실시간 송폼 변경** (방장·부방장, 재생 중): 지금 파트 한 번 더 / 다음 파트 건너뛰기 /
  다음에 원하는 파트 넣기(예: 코러스 1번 추가) / 남은 파트 하나씩 취소 / 이 파트 후 곡 끝내기.
  모든 기기에 즉시 반영되고, 이미 연주 중인 박은 그대로 이어집니다. 악보 보기에서도 **송폼** 버튼으로 쓸 수 있어요.
- **셋리스트**: 곡이 끝나면 정한 간격 뒤 자동으로 다음 곡. 곡 복제·순서 변경·보관함·JSON 내보내기/가져오기.
- **부방장**: 방장이 참가자 목록에서 "부방장으로 임명"하면 방장과 똑같이 곡 편집·시작·정지·송폼 변경을 할 수 있습니다
  (기기 기준이라 재접속해도 유지). 방장을 넘기면 이전 방장은 부방장이 됩니다.
- **악보 보기**: 곡마다 이미지/PDF 악보를 올리면 모든 멤버가 크게 볼 수 있고, 위에 작은 송폼 바와 브리핑이 표시됩니다.
  다음 곡으로 넘어가면 악보도 자동으로 바뀌고, 탭·스와이프·블루투스 페달로 페이지를 넘깁니다.
- **기기별 설정**: 클릭/음성 켜기·볼륨, 목소리(여성·남성·기기 음성), 소리 지연 보정, 화면 꺼짐 방지.

## 실행

Node.js 18 이상이 필요합니다.

```bash
npm install
npm start          # http://localhost:3000
```

같은 Wi-Fi에 있는 폰/탭에서는 `http://<컴퓨터 IP>:3000` 으로 접속합니다. 포트는 `PORT` 환경변수로 바꿀 수 있습니다.

합주실 밖에서도 쓰려면 Render, Railway, Fly.io 같은 Node.js 호스팅에 올리면 됩니다
(시작 명령 `npm start`, WebSocket 지원 필요). 화면 꺼짐 방지 등 일부 기능은 HTTPS에서만 동작합니다.

## 사용법

1. 방장이 이름을 입력하고 **새 방 만들기** → 상단의 방 코드를 눌러 초대 링크 공유.
2. 멤버들은 링크로 들어오거나 방 코드를 입력해 **입장**. (모바일은 처음에 한 번 탭해야 소리가 납니다.)
3. 방장이 셋리스트에 곡을 추가/편집(✎)하고 ▶ **시작**.

## 동기화 방식

- 각 기기가 서버와 주기적으로 핑을 주고받아 서버 시계와의 차이를 측정합니다(왕복 시간이 가장 짧은 측정값 사용).
- 방장이 시작하면 서버가 "지금부터 1.5초 뒤"라는 **서버 기준 시작 시각**과 셋리스트 스냅샷을 모두에게 보냅니다.
- 각 기기는 같은 곡 구조로 같은 타임라인을 계산하고, 시작 시각을 자기 오디오 시계로 변환해서
  Web Audio로 클릭을 미리 예약합니다(출력 지연까지 반영). 재생 중에도 시계 오차를 계속 보정합니다.
- 블루투스 이어폰처럼 소리가 늦게 나는 기기는 **⚙︎ → 지연 보정**으로 맞추면 됩니다.

## 참고

- 음성은 브라우저 내장 음성 합성(Web Speech API)을 사용합니다. 기기마다 목소리가 다르며 ⚙︎에서 고를 수 있습니다.
  음성 엔진이 말을 늦게 시작하는 기기는 "음성 미리 시작" 값을 올리세요.
- 재생 중에는 앱을 화면에 띄워 두세요. 백그라운드로 가면 브라우저가 소리를 멈출 수 있습니다.
- iPhone은 무음 모드에서도 소리가 나도록 설정하지만, iOS 버전이 낮으면 무음 스위치를 꺼야 할 수 있습니다.
- 방 정보는 서버 메모리에만 저장되며, 모두 나간 뒤 30분이 지나면 사라집니다.
  방장의 셋리스트는 방장 기기에 자동 저장되어 다음에 방을 만들 때 그대로 불러옵니다.
- 악보 파일은 서버의 `data/` 폴더(`DATA_DIR`로 변경 가능)에 저장되고 방이 사라질 때 함께 지워집니다.
  올린 악보는 방장 기기에도 보관되어, 서버가 재시작된 뒤 방장이 방을 다시 만들면 자동으로 다시 올라갑니다.
  PDF는 방장 기기에서 페이지별 이미지로 바뀌어 올라갑니다.

## 개발

```
server/index.js      HTTP 정적 파일 + WebSocket 서버
server/rooms.js      방 상태, 방장 권한, 재생 시작/종료
public/js/timeline.js  곡 구조 → 마디/브리핑 타임라인 (서버·클라이언트 공용)
public/js/net.js     WebSocket 연결, 서버 시계 동기화
public/js/engine.js  Web Audio 클릭 예약 + 음성 브리핑
public/js/editor.js  곡 편집기, 곡 보관함
public/js/sheets.js  악보 변환·업로드·기기 보관
public/js/ui.js      아이콘, 파트 색상, 송폼 바
public/js/voice.js   녹음 음성 클립 재생, 파트 이름 → 클립 매칭
public/voice/        음성 클립 (Kokoro TTS로 생성, Apache-2.0)
public/fonts/        나눔스퀘어라운드 (SIL OFL 1.1)
server/sheets.js     악보 파일 저장소
public/js/app.js     화면/상태 관리
```
