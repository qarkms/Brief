# ECHAD — 밴드 실시간 메트로놈 & 파트 브리핑

> 이 백성은 내가 나를 위하여 지었나니 나를 찬송하게 하려 함이니라 (사 43:21)
> *This people have I formed for myself; they shall shew forth my praise.* (Isaiah 43:21, KJV)

한 방에 들어온 밴드 멤버들의 핸드폰/태블릿에서 **메트로놈 클릭과 음성 브리핑이 동시에** 재생되는 웹앱입니다.
방장이 ▶ 시작을 누르면 모든 기기에서 같은 순간에 카운트인 → 곡이 시작되고,
각 파트(Intro, Verse, Chorus …)가 시작하기 **한 마디 전**에 전자 음성으로 파트 이름을 알려줍니다.

앱 설치 없이 브라우저로 접속하면 되고, "홈 화면에 추가"하면 앱처럼 쓸 수 있습니다.

## 기능

- **메트로놈**: 마디 첫 박·새 파트 첫 박 강조, 6/8·9/8·12/8은 3박마다 중간 강세.
  - **소리**(기기마다 선택): 기본 · 소프트 · 우드블록 · 하이클릭 · 여성 목소리 · 남성 목소리.
    목소리 메트로놈은 박마다 "1 2 3 4"를 세고(클릭 쪼개기 8분이면 "n"도), 브리핑과 겹치는 박은 부드러운 클릭으로 대신합니다.
  - **박자**: 2/4, 3/4, 4/4, 5/4, 6/8, 7/8, 12/8 … (곡 기본값 + 파트별 변경)
  - **클릭 쪼개기**: 박과 박 사이에 작은 클릭을 더 넣어 박을 잡기 쉽게 합니다.
    "1 2 3 4"(안 함) / "1 n 2 n 3 n 4 n"(8분) / "1 e n 2 e n"(셋잇단) / "1 e n a"(16분).
    곡 기본값 + 파트별 변경. 메인 화면의 **클릭 쪼개기** 버튼을 누르면 재생 중에도 바로 바뀌고 모든 기기에 반영됩니다.
  - 곡 중간 박자 변경(예: 4/4 → 2/4 한 마디 → 4/4)은 편집기의 **"+ 박자 변경 마디"** 로 넣습니다.
    이 마디는 기본으로 브리핑을 하지 않고, 다음 파트 브리핑은 그 마디 첫 박에 나옵니다.
- **음성 브리핑**: 각 파트가 시작하기 한 마디 전, 그 마디 첫 박에 파트 이름을 알려줍니다.
  미리 녹음된 음성(여성/남성)을 박에 맞춰 예약 재생하므로 클릭과 정확히 맞습니다.
  "Verse 2", "코러스 1", "V1", "C" 같은 이름도 알아듣고, 녹음에 없는 문구(직접 쓴 한글 등)는 기기 음성으로 읽습니다.
- **카운트 음성**: 카운트인 마지막 마디를 "1 2 3 4"(6/8은 1~6)로 셉니다.
- **곡 구조 편집**: 파트 이름·마디 수(− 8마디 +), 끌어서 순서 바꾸기, 파트 사이 "+"로 끼워넣기,
  파트별 BPM·박자·음표·음성 문구·브리핑 켜고 끄기.
- **실시간 송폼 변경** (방장·부방장, 재생 중): 지금 파트 한 번 더 / 다음 파트 건너뛰기 /
  다음에 원하는 파트 넣기(예: 코러스 1번 추가) / **+1 마디**(지금 파트를 한 마디 늘림) / 남은 파트 하나씩 취소 / 이 파트 후 곡 끝내기.
  모든 기기에 즉시 반영되고, 이미 연주 중인 박은 그대로 이어집니다.
  악보 보기에서는 악보 바로 위 도구 줄(한 번 더 · 건너뛰기 · 이 파트 후 끝 · + 파트)로 한 번에 바꿀 수 있어요.
- **셋리스트**: 곡이 끝나면 정한 간격 뒤 자동으로 다음 곡. 곡 복제·순서 변경·보관함·JSON 내보내기/가져오기.
- **혼자 연습** (방장·부방장이 아닌 멤버): 방장이 만든 방의 송폼으로 **내 기기에서만** 메트로놈·브리핑을 돌립니다.
  곡·시작 파트를 각자 고르고, 실시간 송폼 버튼(한 번 더, +1 마디 등)도 나에게만 적용돼요.
  방장이 모두에게 시작하면 혼자 연습은 멈추고 함께 재생으로 바뀝니다.
- **참가자 목록**: 한 번이라도 들어온 사람은 나가도 목록에 남고, 지금 접속 중인지(초록 점) 또는 마지막 접속 시각이 함께 보입니다.
  위쪽 사람 버튼의 숫자는 "접속 중/전체"입니다. 방장은 접속하지 않은 사람도 부방장으로 임명할 수 있고, "목록에서 빼기"로 정리할 수 있어요.
- **부방장**: 방장이 참가자 목록에서 "부방장으로 임명"하면 방장과 똑같이 곡 편집·시작·정지·송폼 변경을 할 수 있습니다
  (기기 기준이라 재접속해도 유지). 방장을 넘기면 이전 방장은 부방장이 됩니다.
- **악보 보기**: 곡마다 이미지/PDF 악보를 올리면 모든 멤버가 크게 볼 수 있고, 위에 작은 송폼 바와 브리핑이 표시됩니다.
  다음 곡으로 넘어가면 악보도 자동으로 바뀌고, 탭·스와이프·블루투스 페달로 페이지를 넘깁니다.
  악보 위 송폼은 글자가 잘리지 않을 만큼 지금 파트부터 보여주고, 지나간 파트는 사라지며, 못 들어간 파트 중 맨 앞 것을 **NEXT**로 미리 보여줍니다.
  - **내 악보**: 악보 보기 위쪽의 [공용 악보 | 내 악보]에서 "내 악보"를 고르고 이미지·PDF를 올리면, 이 기기에만 저장되어 **나만** 그 악보를 봅니다
    (서버에 올라가지 않음). 곡 제목으로 묶여서 다른 방·셋리스트의 같은 곡에서도 나오고, 내 악보가 있으면 그것을 먼저 보여줍니다.
  - **나만 보는 필기**: 악보 보기의 "필기"로 펜(빨강·파랑·검정)·형광펜·지우개·되돌리기. 이 기기에만 저장되어 다른 멤버에게는 안 보입니다.
    애플펜슬을 쓰면 그때부터 손가락 터치는 그리지 않아 손바닥이 닿아도 괜찮아요.
- **홈 화면**: 앱을 열면 홈이 먼저 나옵니다 (초대 링크로 열거나 방 안에서 새로고침하면 그 방으로 바로).
  - **내 방**: 만들었거나 들어갔던 방 목록. 지금 접속 인원·재생 중인 곡이 보이고, 누르면 바로 입장합니다.
    방장은 닫힌 방(서버에서 지워진 방)을 **같은 코드로 다시 열 수** 있어요.
  - **보관함**: 곡(송폼 + 악보)과 셋리스트를 이 기기에 저장하고 편집합니다. 방 없이도 만들 수 있고,
    셋리스트에서 바로 방을 열 수 있어요. 홈에서 넣은 악보는 방에서 쓸 때 자동으로 서버에 올라갑니다.
    백업 파일로 내보내기/불러오기 가능 (악보 그림은 기기에만 보관).
  - 방 안에서도 "셋리스트 보관함에 저장", "보관함에서 추가"(곡·셋리스트)로 오갈 수 있습니다.
- **소리 지연 맞추기**: 블루투스 장비는 소리가 화면보다 늦게 나옵니다. 설정의 **"탭으로 지연 맞추기"** 에서
  들리는 클릭 16번에 맞춰 탭하면 얼마나 늦는지 재서 블루투스 보정값으로 저장합니다(스피커 값도 따로 저장 가능).
  - **블루투스 보정 켜기/끄기**: 메인 화면의 "블루투스 보정" 버튼이나 설정에서 직접 전환.
  - **자동 전환**: 출력 장치가 바뀌면(연결/해제) 브라우저가 알려주는 정보로 블루투스인지 판단해 자동으로 켜고 끕니다.
    판단할 수 없는 기기(iPhone/iPad Safari 등)에서는 장치가 바뀔 때 "블루투스 보정을 쓸까요? 켜기/끄기"를 물어봅니다.
- **기기별 설정**: 클릭/음성 켜기·볼륨, 메트로놈 소리, 목소리(여성·남성·기기 음성), 소리 지연 보정, 화면 꺼짐 방지.

## 실행

Node.js 18 이상이 필요합니다.

```bash
npm install
npm start          # http://localhost:3000
```

같은 Wi-Fi에 있는 폰/탭에서는 `http://<컴퓨터 IP>:3000` 으로 접속합니다. 포트는 `PORT` 환경변수로 바꿀 수 있습니다.

합주실 밖에서도 쓰려면 Render, Railway, Fly.io 같은 Node.js 호스팅에 올리면 됩니다
(시작 명령 `npm start`, WebSocket 지원 필요). 화면 꺼짐 방지 등 일부 기능은 HTTPS에서만 동작합니다.

### 무료 서버에서 방·악보 오래 보관하기

- **잠들지 않게:** Render 무료 서버는 15분 동안 접속이 없으면 잠듭니다. UptimeRobot, cron-job.org 같은 무료 서비스로
  `https://<주소>/healthz` 를 5분마다 열게 하면 깨어 있습니다.
- **Supabase에 함께 저장:** 서버 환경변수에 `SUPABASE_URL`(Project URL)과 `SUPABASE_SERVICE_KEY`(secret 키 또는 service_role 키)를
  넣으면 방(`rooms.json`)과 악보가 Supabase Storage의 비공개 버킷 `echad`(`SUPABASE_BUCKET`로 변경 가능)에도 저장됩니다.
  서버 디스크가 지워져도 켜질 때 방을 다시 가져오고, 악보는 처음 열 때 내려받습니다. 버킷은 처음 켤 때 자동으로 만들어지며,
  무료 프로젝트가 일시정지되지 않도록 서버가 6시간마다 가볍게 접속합니다. 환경변수가 없으면 서버 디스크만 사용합니다.

## 사용법

1. 방장이 이름을 입력하고 **새 방 만들기** → 상단의 방 코드를 눌러 초대 링크 공유.
2. 멤버들은 링크로 들어오거나 방 코드를 입력해 **입장**. (모바일은 처음에 한 번 탭해야 소리가 납니다.)
3. 방장이 셋리스트에 곡을 추가/편집(✎)하고 ▶ **시작**.

## 동기화 방식

- 각 기기가 서버와 주기적으로 핑을 주고받아 서버 시계와의 차이를 측정합니다(왕복 시간이 가장 짧은 측정값 사용).
- 방장이 시작하면 서버가 "지금부터 1.5초 뒤"라는 **서버 기준 시작 시각**과 셋리스트 스냅샷을 모두에게 보냅니다.
- 각 기기는 같은 곡 구조로 같은 타임라인을 계산하고, 시작 시각을 자기 오디오 시계로 변환해서
  Web Audio로 클릭을 미리 예약합니다(출력 지연까지 반영). 재생 중에도 시계 오차를 계속 보정합니다.
- 블루투스 이어폰처럼 소리가 늦게 나는 기기는 **⚙︎ → 지연 보정**으로 맞추면 됩니다.

## 참고

- 음성은 브라우저 내장 음성 합성(Web Speech API)을 사용합니다. 기기마다 목소리가 다르며 ⚙︎에서 고를 수 있습니다.
  음성 엔진이 말을 늦게 시작하는 기기는 "음성 미리 시작" 값을 올리세요.
- 재생 중에는 앱을 화면에 띄워 두세요. 백그라운드로 가면 브라우저가 소리를 멈출 수 있습니다.
- iPhone은 무음 모드에서도 소리가 나도록 설정하지만, iOS 버전이 낮으면 무음 스위치를 꺼야 할 수 있습니다.
- 방(이름·셋리스트·방장·부방장)은 서버의 `data/rooms.json`에 저장되어 서버를 다시 켜도 남고,
  아무도 들어오지 않은 채 14일이 지나면 지워집니다. Render 무료 요금제처럼 디스크가 초기화되는 곳에서는
  서버가 잠들면 방이 사라질 수 있지만, **한 번이라도 들어갔던 멤버라면 방장이 없어도 코드만 입력하면** 기기에 저장된 사본으로
  같은 코드·셋리스트의 방이 다시 열립니다. 방장·부방장은 나중에 들어와도 그대로 방장·부방장이에요
  (사본에는 방장 토큰·기기 키의 지문만 있어서 사본으로 방장 행세를 할 수는 없습니다).
- 악보 파일은 서버의 `data/` 폴더(`DATA_DIR`로 변경 가능)에 저장되고 방이 사라질 때 함께 지워집니다.
  올린 악보는 방장 기기에도 보관되어, 서버가 재시작된 뒤 방장이 방을 다시 만들면 자동으로 다시 올라갑니다.
  PDF는 방장 기기에서 페이지별 이미지로 바뀌어 올라갑니다.

```
public/js/timeline.js  곡 구조 → 마디/브리핑 타임라인 (서버·클라이언트 공용)
public/js/net.js     WebSocket 연결, 서버 시계 동기화
public/js/engine.js  Web Audio 클릭 예약 + 음성 브리핑
public/js/editor.js  곡 편집기, 곡 보관함
public/js/sheets.js  악보 변환·업로드·기기 보관
public/js/ui.js      아이콘, 파트 색상, 송폼 바

public/fonts/        나눔스퀘어라운드 (SIL OFL 1.1)
server/sheets.js     악보 파일 저장소
public/js/app.js     방 화면/상태 관리
public/js/home.js    홈 화면 (내 방, 보관함, 내 정보)
public/js/library.js 이 기기의 보관함·내 방 목록 저장
public/js/ink.js     악보 필기 (기기에만 저장)
```
